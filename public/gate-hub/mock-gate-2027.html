Marking and rules

  • MCQ: a wrong answer costs ⅓ of the question’s marks (−⅓ for 1 mark, −⅔ for 2 marks). Leaving it blank costs nothing.
  • MSQ: select every correct option. You score only for the exact correct set, and there is no negative marking.
  • NAT: type a number. It is accepted if it is within the stated tolerance. No negative marking.
  • Time: 180 minutes. The test submits itself when the clock reaches zero. Pause exists for real interruptions; the real exam has none.
  • Progress is saved on this device, so you can leave and resume.

Your full mocks

    Each mock is a random draw from the hub’s question banks (about 1,190 questions including numerical-answer ones), so repeated mocks will overlap. Which questions count for 1 or 2 marks is assigned by length and effort, because the original practice questions carry no marks. Treat the score as a practice signal, not a prediction of your GATE score.
