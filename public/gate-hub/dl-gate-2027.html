1. Number Systems & Computer Arithmetic

Base conversion, signed representations, overflow, codes, and IEEE 754 floating point — the arithmetic that every later circuit is built to compute.

Positional systems & conversion

A number in base r is a sum of digit × rposition. Common bases: binary (2), octal (8, groups of 3 bits), hexadecimal (16, groups of 4 bits). To convert integer → base r, divide repeatedly by r and read remainders bottom-up; for the fractional part multiply repeatedly by r and read the integer parts top-down.

GATE angle
2's complement has the asymmetric range (one more negative than positive), and sign extension (copy the MSB leftwards) preserves the value. Only 2's complement has a unique zero.

Overflow in signed addition

Overflow happens when the true sum is outside the representable range. Detect it as: carry into the MSB ≠ carry out of the MSB, or equivalently both operands have the same sign but the result has the opposite sign. Adding numbers of opposite sign never overflows. Carry-out alone is the overflow flag for unsigned arithmetic.

Worked numerical — precision loss
Single precision has 24 significant bits, so integers above 224 = 16 777 216 are no longer all representable: 16777216 + 1 rounds back to 16777216. Fixed point and range summary

  • Fixed point: a fixed number of integer and fraction bits. An unsigned Qm.n format with m integer bits and n fraction bits has resolution 2−n and range 0 … 2m − 2−n.
  • Multiplying two n-bit unsigned numbers needs up to 2n bits for the product; adding two n-bit numbers needs up to n + 1 bits.
  • Sign extension: to widen a 2's complement number, copy the sign bit into the new high bits (e.g. 1101 → 1111 1101 keeps −3).

3. Minimisation: K-Maps & Quine–McCluskey

Turn a truth table into the cheapest two-level circuit by grouping adjacent 1s.

K-map rules

  • Rows and columns are labelled in Gray-code order (00, 01, 11, 10) so neighbouring cells differ in one variable.
  • Group 1s (for SOP) in rectangles of size 1, 2, 4, 8, 16 — always a power of 2. A group of 2k cells removes k variables.
  • Groups may wrap around edges (the map is a torus), and may overlap. Use the fewest, largest groups that cover every 1.
  • For POS, group the 0s to get f' as SOP, then complement (or read the groups as sum terms with literals inverted).
  • Every cell in an n-variable map has exactly n neighbours (4 in a 4-variable map).

Quine–McCluskey (tabular) method

  1. List all minterms (and don't cares) in binary, grouped by the number of 1s.
  2. Repeatedly combine pairs from adjacent groups that differ in exactly one bit, replacing that bit by –; mark combined terms as used.
  3. Terms that can no longer combine are the prime implicants.
  4. Build a PI chart (rows = PIs, columns = minterms, excluding don't cares); pick essential PIs first, then cover the rest with the fewest/cheapest PIs (Petrick's method for cyclic charts).
GATE angle
Typical questions: "number of prime implicants", "number of essential prime implicants", "minimum number of literals/gates/NAND gates". Remember: minimum SOP ≠ unique; PIs count is unique; and the answer changes if you must also realise the complement or use POS.

Hazards (glitches)

A hazard is a momentary wrong output caused by unequal gate delays when inputs change.

  • Static-1 hazard: output should stay 1 but briefly drops to 0 — occurs in SOP when two adjacent 1-cells are covered by different product terms with no common term.
  • Static-0 hazard: output should stay 0 but pulses 1 (in POS circuits).
  • Dynamic hazard: output changes 3 or more times when it should change once.
Worked numerical — removing a static-1 hazard
f = AB + A'C. With B = C = 1 and A switching 1 → 0, f should stay 1, but AB falls before A'C rises (the inverter delay) → glitch. Add the consensus term BC, which stays 1 throughout: f = AB + A'C + BC. On the K-map this is the extra group straddling the two adjacent cells.
Remember
Hazard-free covers need every pair of adjacent 1s covered by some single product term — that can mean using non-essential PIs, so the hazard-free circuit is not the minimal one.

5. Latches & Flip-Flops

The one-bit memory cells. A latch is level-sensitive; a flip-flop changes only on a clock edge.

SR latch

Two cross-coupled NOR (or NAND) gates. For the NOR version: S = 1 sets Q = 1, R = 1 resets Q = 0, S = R = 0 holds, and S = R = 1 is forbidden (both outputs go 0, and the next state is unpredictable if both return to 0 together). The NAND version is active-low (S' and R'), with S' = R' = 0 forbidden. Adding a clock/enable gives a gated SR latch; connecting S = D, R = D' removes the forbidden state and gives the D latch.

Triggering and the race-around condition

  • Level-triggered (latch): output follows input for the whole time the clock is high.
  • Edge-triggered: samples inputs only at the rising (or falling) edge.
  • Race-around: a level-triggered JK with J = K = 1 toggles repeatedly while the clock stays high, if the clock pulse is longer than the propagation delay. Cures: master–slave or edge-triggered design, or a pulse shorter than tpd (impractical).
  • Master–slave: two latches on opposite clock phases — the master samples while CLK = 1, the slave copies at the falling edge, so the output changes once per cycle.

Timing parameters

  • Setup time tsu: data must be stable before the active edge. Hold time th: data must stay stable after the edge. Clock-to-Q tcq: delay from the edge to the new output.
  • Minimum clock period between two flip-flops: T ≥ tcq + tcomb(max) + tsu (plus clock skew). Hold condition: tcq(min) + tcomb(min) ≥ th. Violating setup is cured by a slower clock; violating hold is not.
Worked numerical — maximum clock frequency
Q: tcq = 2 ns, longest combinational delay = 5 ns, tsu = 1 ns (no skew). Find the maximum clock frequency.
A: Tmin = 2 + 5 + 1 = 8 ns → fmax = 1 / 8 ns = 125 MHz.

6. Counters & Shift Registers

Flip-flops wired together to count clock pulses or to move bits around.

Asynchronous (ripple) counters

Each flip-flop (toggle mode, J = K = 1 or T = 1) is clocked by the output of the previous one, so the clock ripples through. An n-bit ripple counter counts 0 … 2n − 1 (modulus 2n); each stage divides frequency by 2, so the n-th output has frequency f/2n.

  • Up counter: clock from Q (falling-edge FFs) or from Q' (rising-edge FFs). Down counter: the opposite connection.
  • Drawback: delays add up. For an n-bit ripple counter the output settles after n × tpd, so fmax ≈ 1 / (n · tpd) and decoding glitches appear while it ripples.
Worked numerical
Q: A 4-bit ripple counter uses flip-flops with tpd = 20 ns. Maximum clock frequency?
A: Settling time = 4 × 20 = 80 ns → fmax = 1 / 80 ns = 12.5 MHz. A synchronous 4-bit counter needs only one tpd plus the AND-gate delay, so it runs much faster.

Synchronous counters

All flip-flops share one clock, so every output changes together after a single tpd. The T-inputs come from combinational logic; for an up counter Ti = Q0·Q1·…·Qi−1. They are faster but need extra gates.

Modulo-N counters

  • Flip-flops needed: ⌈log₂ N⌉ (mod-10 → 4, mod-60 → 6).
  • With an asynchronous reset: decode state N with a NAND gate and feed it to the clear inputs. The invalid state N exists only for a few nanoseconds (a glitch).
  • Output frequency of a mod-N counter = fclk / N (so 1.6 MHz into a mod-16 gives 100 kHz at its MSB).
Worked numerical — mod-6 from a 3-bit ripple counter
Count: 000 → 001 → 010 → 011 → 100 → 101 → (110 appears for an instant) → 000

7. Finite State Machines & Synchronous Design

Sequential circuits with state: the next state depends on the present state and input; the output depends on the machine type.

  • Mealy → Moore: may need up to (states × distinct outputs) states.
  • Flip-flops needed for N states: ⌈log₂ N⌉ (5 states → 3 flip-flops).

Synchronous design procedure

  1. Draw the state diagram / state table from the specification.
  2. Minimise states (merge equivalent states).
  3. Assign binary codes to states (number of flip-flops = ⌈log₂ N⌉).
  4. Use the flip-flop excitation table to derive flip-flop input equations and output equations (K-maps; unused states are don't cares).

State minimisation

Two states are equivalent if, for every input sequence, they produce the same outputs (and move to equivalent states). Procedure: partition states by output behaviour, then keep splitting while their next states fall in different blocks (partition refinement — the same idea as DFA minimisation). Equivalent states merge, reducing the number of flip-flops and logic.

8. Memory & Programmable Logic

Memories double as logic: a ROM is a lookup table, and PLA/PAL/FPGA devices let you "program" a Boolean function instead of wiring gates.

Memory sizing

  • A memory with k address lines holds 2k words; with w bits per word, capacity = 2k × w bits. Address lines needed for N words = ⌈log₂ N⌉.
  • 12 address lines × 8-bit words → 4096 × 8 = 32 768 bits = 4 KB.
  • Building a bigger memory from smaller chips: chips needed = (total words ÷ words per chip) × (total width ÷ chip width). A 16K × 16 memory from 4K × 8 chips: (16K/4K) × (16/8) = 4 × 2 = 8 chips. The extra high-order address lines (2 here) drive a decoder that selects the chip row.
  • RAM is volatile read/write (SRAM: flip-flop cells, fast; DRAM: capacitor cells, dense, needs refresh). ROM is non-volatile (mask ROM, PROM, EPROM, EEPROM, Flash).

ROM as a combinational circuit

A ROM with n address lines and m data lines is an n-to-2n decoder followed by m OR gates: the decoder produces every minterm and each output is the OR of the minterms stored as 1. Hence a 2n × m ROM can implement any m Boolean functions of n variables; its size is 2n × m bits. A ROM with 4 inputs and 3 outputs holds 16 × 3 = 48 bits. It is simple but wasteful when only a few minterms are needed, since the table doubles with each extra input.

Other useful building blocks

  • Tri-state buffer: output is 0, 1 or high-impedance (Z). Several tri-state drivers can share one bus if exactly one is enabled at a time.
  • Open-collector / open-drain outputs allow a wired-AND on a shared line with a pull-up resistor.
  • Fan-in = number of inputs a gate accepts; fan-out = number of gate inputs one output can drive. A wide AND with limited fan-in is built as a tree of smaller gates, adding delay of about ⌈logk n⌉ levels.
  • Propagation delay: critical path = the longest delay from any input to any output; it sets the clock-period limit of a synchronous design.

9. Arithmetic Circuits & Error-Control Codes

Multi-digit adders and multipliers, and the redundancy bits that let hardware detect and correct bit errors.

BCD adder

Add two BCD digits with a 4-bit binary adder. If the binary sum is greater than 9 (that is, the carry-out is 1, or the sum is 1010–1111), add 6 (0110) to correct it and propagate a decimal carry. The correction condition is K = Cout + S3S2 + S3S1.

Worked numerical
8 + 5 = 13: 1000 + 0101 = 1101 (13 > 9) → add 0110: 1101 + 0110 = 1 0011 → carry 1, digit 0011 → BCD 0001 0011 = 13 ✔.

Multipliers

  • Shift-and-add: for each multiplier bit that is 1, add the shifted multiplicand — n cycles for n-bit operands, 2n-bit product.
  • Array multiplier (n × n): n² AND gates generate the partial products; they are added by n(n−1) adders in total (n(n−2) full adders and n half adders). A 4 × 4 array multiplier therefore uses 16 AND gates, 8 full adders and 4 half adders. It is fast (delay grows linearly with n) but large.
  • Booth's algorithm handles signed 2's complement operands by recoding runs of 1s in the multiplier (the pair Q₀Q₋₁ = 10 → subtract, 01 → add, 00/11 → shift only).
  • Adders recap: ripple-carry delay ∝ n; carry-lookahead is about constant to log n; carry-select and carry-skip adders sit in between.

Parity and Hamming distance

  • Even parity: add a bit so the total number of 1s is even (odd parity: odd). A single parity bit detects any odd number of bit errors but cannot locate them and misses even-numbered errors.
  • Hamming distance d(x, y) = number of positions where x and y differ. The minimum distance dmin of a code decides its power: 
    detect up to  d_min − 1  errors
correct up to ⌊(d_min − 1)/2⌋ errors
detect e and correct t simultaneously if d_min ≥ e + t + 1  (e ≥ t)
  • A code with dmin = 5 detects up to 4 errors or corrects up to 2. A code with dmin = 3 corrects 1 error; adding an overall parity bit makes dmin = 4 (SECDED: single-error-correct, double-error-detect).
Worked numerical
d(10110, 11011): XOR = 01101 → three 1s → distance 3. Even parity bit for 1011011 (five 1s) = 1.

CRC (brief)

A cyclic redundancy check divides the message (shifted left by the degree of the generator polynomial) by the generator using XOR (mod-2) division; the remainder is appended. A receiver recomputes it; a non-zero remainder signals an error. A CRC with a degree-r generator detects all burst errors of length ≤ r and all single-bit errors if the generator has at least two terms.

10. High-Yield Sequential & Boolean Methods

Canonical methods for the remaining timing, asynchronous-circuit, race/hazard, LFSR and Shannon-expansion patterns.

Asynchronous sequential circuits

🟢 Must RememberFundamental-mode assumption

For fundamental-mode analysis, only one input changes at a time and the circuit is allowed to reach a stable state before the next input change. Do not apply synchronous edge-triggered assumptions.

⚠️ GATE FavouriteStable-state analysis

Write the next-state equation, identify states satisfying Qnext=Q for the current input, then check whether transitions under the permitted input changes lead to the intended stable state.

🟡 Common TrapRace vs hazard

A race concerns multiple state variables changing and potentially reaching different final states. A hazard is an unwanted transient caused by unequal propagation delays in a combinational path.

🟢 Must RememberCritical race

A race is critical when different possible orders of state-variable changes can lead to different stable states. State assignment should avoid assigning adjacent transitions to codes requiring multiple simultaneous bit changes.

⚠️ GATE FavouriteEssential hazard

Occurs in asynchronous circuits because a feedback path has unequal delays. Unlike a static/dynamic logic hazard, it cannot generally be removed by merely adding a redundant combinational consensus term; the feedback path must be designed with appropriate delays/structure.

🧮 Formula / RuleStatic-1 hazard

For SOP logic, if adjacent 1-minterms are covered by separate product terms but not a common implicant, unequal delays can create a temporary 0. Add the consensus/overlap implicant when appropriate.

Timing-diagram workflow

How to solve a flip-flop timing question
  1. Identify the active clock edge/level.
  2. Evaluate J/K, D or T immediately before the active edge.
  3. Apply the characteristic equation: D → Qnext=D; T → Qnext=Q⊕T; JK → 00 hold, 01 reset, 10 set, 11 toggle.
  4. Apply preset/clear first if asynchronous controls are asserted.
  5. Only then draw Q and account for clock-to-Q delay if the question asks for waveform timing.

State assignment

💡 ShortcutAdjacent transitions

Prefer state codes that differ in one bit for transitions that occur frequently. This reduces race risk in asynchronous implementations and often simplifies excitation equations.

🟡 Common TrapDon't confuse minimisation with assignment

State minimisation merges equivalent states; state assignment maps the remaining states to binary codes. They are different design stages.

LFSR

🟢 Must RememberLinear feedback

An n-bit maximal-length LFSR can generate at most 2n−1 nonzero states when its feedback polynomial is primitive. The all-zero state is a lock-up state for a standard XOR-feedback LFSR.

🧮 Formula / RuleState transition method

Write the current register, compute the feedback XOR from the specified taps, shift in the feedback bit, and repeat until a state repeats. The number of distinct nonzero states is the period.

Shannon expansion

🧮 Formula / RuleShannon expansion

For variable x: F = x·F|x=1 + x'·F|x=0. It is the algebraic basis of MUX implementation: use x as the select and the two cofactors as the data inputs.

Representative worked problems

Q1 · LFSR period

Problem: An n=4 maximal-length XOR LFSR is initialized to any nonzero state. What is its maximum period?

Method: A primitive 4-bit LFSR visits every nonzero state exactly once.

24−1 = 15. Maximum period = 15 clocks. The zero state must be avoided.

Q2 · Shannon expansion / MUX

Problem: Express F(A,B,C)=Σm(1,2,5,7) using A as the MUX select.

Method: Compute cofactors. For A=0, minterms 1,2 correspond to BC=01,10, giving F0=B⊕C. For A=1, minterms 5,7 correspond to BC=01,11, giving F1=C.

Therefore F=A'·(B⊕C)+A·C. A 2:1 MUX uses select A, D0=B⊕C and D1=C.

Q3 · Static-1 hazard recognition

Problem: A two-level SOP changes from one input combination where F=1 to an adjacent combination where F=1, but the two points are covered by different product terms with no common implicant. What failure should you suspect?

Method: Adjacent 1-cells should have an overlapping implicant for a hazard-free static-1 transition.

Suspect a static-1 hazard. Add the appropriate consensus/overlap term if it is logically redundant and permitted by the implementation.

Q4 · Flip-flop timing

Problem: A positive-edge D flip-flop sees D=1 immediately before one rising edge and D=0 immediately before the next rising edge. Ignore asynchronous inputs. What are the sampled Q values?

Method: Sample D only at the active edge; between edges Q retains its stored value.

After the first rising edge Q becomes 1; after the second rising edge Q becomes 0. Changes in D between those edges do not immediately change Q.

Q16 · State minimisation of a DFA by partition refinement
A DFA over {0, 1} has start state A, accepting states {C, D, E} and transitions (on 0, on 1): A→(B,C), B→(A,D), C→(E,F), D→(E,F), E→(E,F), F→(F,F). How many states does the minimal equivalent DFA have, and which states merge?
  1. 3 states; A≡B and C≡D≡E
  2. 4 states; only C≡D and D≡E merge
  3. 3 states; A≡B and C≡D but E stays separate
  4. 5 states; only A≡B merge
Partition refinement (Myhill–Nerode / table filling):
 P0  = {C, D, E} (accepting)  |  {A, B, F} (non-accepting)
 P1  : look at where each state goes under 0 and 1, as block labels (X = {C,D,E}, Y = {A,B,F}):
       C → (E,F) = (X,Y)   D → (E,F) = (X,Y)   E → (E,F) = (X,Y)      → {C, D, E} stays together
       A → (B,C) = (Y,X)   B → (A,D) = (Y,X)   F → (F,F) = (Y,Y)      → F separates from A and B
       P1 = {C,D,E} | {A,B} | {F}
 P2  : A → (B,C) = ({A,B},{C,D,E}),  B → (A,D) = ({A,B},{C,D,E})   → same;   C, D, E all → ({C,D,E},{F}) → same
       No block splits, so P2 = P1.
Equivalence classes: {A,B}, {C,D,E}, {F}  →  3 states in the minimal DFA.
Language accepted: exactly one 1, i.e. 0*10*. The three classes are 'no 1 seen yet' {A,B}, 'exactly one 1 seen' {C,D,E} and the dead state {F} (a second 1).

Check: partition refinement was run by program; classes [A,B], [C,D,E], [F].
Trap: E looks different because it loops to itself on 0, but loops are irrelevant — what matters is that E, C and D have identical futures.

Correct: Option 1 — 3 states, with A≡B and C≡D≡E merged.

Q17 · LFSR sequence length and Johnson counter states
(i) A 4-bit shift register shifts right each clock; the new MSB is Q0 ⊕ Q1 (the XOR of the two least significant bits). Starting from 1000, how many clocks before the state repeats, and which state can never occur? (ii) How many distinct states does a 4-bit Johnson (twisted-ring) counter use, compared with a 4-bit ring counter?
  1. 15 states, 0000 never occurs; Johnson 8 vs ring 4
  2. 16 states, 0000 occurs; Johnson 8 vs ring 4
  3. 15 states, 0000 never occurs; Johnson 16 vs ring 4
  4. 7 states, 1111 never occurs; Johnson 8 vs ring 4
(i) State = Q3Q2Q1Q0, shift right, feedback bit = Q1 ⊕ Q0 enters Q3.
     1000 → 0100 → 0010 → 1001 → 1100 → 0110 → 1011 → 0101 → 1010 → 1101 → 1110 → 1111 → 0111 → 0011 → 0001 → 1000
     15 distinct states before returning to 1000 — the maximum possible 2^4 − 1 (a maximal-length sequence).
     The all-zero state 0000 maps to itself (feedback 0 ⊕ 0 = 0), so it is a LOCK-UP state; it never occurs in the 15-state cycle and must be avoided at start-up.
     A poor tap choice gives a shorter cycle: feedback Q0 ⊕ Q2 from 0001 repeats after only 6 states.
(ii) Johnson counter (feedback = complement of the last bit): 0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000: 2n = 8 states.
     Ring counter (one hot bit circulating): n = 4 states.   Mod-N Johnson needs N/2 flip-flops, a ring needs N.
     Johnson states are decoded with 2-input gates (any state is identified by two adjacent bits).

Check: the 15-state cycle and the 6-state cycle for the other tap pair were produced by program; the Johnson cycle has 8 states.
Trap: with XOR feedback, the all-zeros state is the illegal one; with XNOR feedback it would be all-ones.

Correct: Option 1 — period 15 with 0000 as the lock-up state; Johnson uses 8 states, a ring counter 4.

Q18 · Static-1 hazard and its removal
For f = AB + A'C (implemented as two AND gates feeding an OR gate, with an inverter on A), which input transition can cause a static-1 hazard, and which extra product term removes it?
  1. A changes while B = C = 1; add the term BC
  2. B changes while A = C = 1; add the term AC
  3. C changes while A = 0, B = 1; add the term A'B
  4. A changes while B = 0, C = 1; add the term B'C
K-map of f = AB + A'C (cells ABC):  ones at 011 (A'C), 001 (A'C), 110 (AB), 111 (AB) and 011/111 share B = C = 1.
Prime implicants in the cover: AB (cells 110, 111) and A'C (cells 001, 011). The adjacent cells 011 and 111 are both 1 but belong to DIFFERENT groups.

When A switches 1 → 0 with B = C = 1: AB falls to 0 immediately, but A'C rises only after the inverter delay.
For a short time BOTH terms are 0 → the output momentarily drops to 0 (a glitch) even though it should stay 1: a static-1 hazard.

Fix: add the redundant consensus term BC (covers 011 and 111).  f = AB + A'C + BC — logically the same function, but a single product term now holds the output at 1 during the transition.
The adjacency scan of the 3-variable map finds exactly one hazardous pair (011, 111).
Check: all adjacent minterm pairs were scanned by program (only 011–111 qualifies), and f = AB + A'C + BC was confirmed equal to AB + A'C on all 8 inputs.
Rules: static-1 hazards in SOP circuits come from adjacent 1-cells in different groups; static-0 hazards appear in POS circuits; a redundant (consensus) term removes it, at the price of a larger circuit.

Correct: Option 1 — A changing with B = C = 1 causes the hazard; adding BC removes it.
