2. Linear Algebra

Matrices, determinants, rank, systems of equations, and eigenvalues — all connected by a handful of identities.

Determinant properties (n × n matrix) 🟢 Core

det(AB) = det(A)·det(B)
det(Aᵀ) = det(A)
det(kA) = kⁿ·det(A)
det(A⁻¹) = 1/det(A)
Swapping two rows → sign changes
Two equal rows or a zero row → det = 0
Row op "add k·row i to row j" → unchanged
Triangular matrix: product of diagonal
Invertibility — all equivalent:
A is invertible
det(A) ≠ 0
rank(A) = n
Ax = 0 has only x = 0
columns are linearly independent
no eigenvalue is 0
Worked numerical
If A is 3×3 with det(A) = 4, then det(2A) = 2³·4 = 32; det(A⁻¹) = 1/4; det(A²) = 16.

Rank and systems of linear equations 🟢 Core

  • Rank = number of non-zero rows in row-echelon form = dimension of the column space. rank(A) ≤ min(m, n).
  • Rank–nullity: rank(A) + nullity(A) = n (number of columns). A 5×7 matrix of rank 3 has nullity 4.
  • Ax = b is consistent iff rank(A) = rank([A | b]). Unique solution iff the common rank = n (number of unknowns); infinitely many iff rank < n; none if the ranks differ.
  • Homogeneous Ax = 0 always has the trivial solution; a square system has a non-trivial one iff det(A) = 0. If m < n there is always a non-trivial solution.
Worked numerical — solving a 3×3 system
x +  y +  z =  6
     2y + 5z = −4
2x + 5y −  z = 27
R3 ← R3 − 2R1:   3y − 3z = 15  → y − z = 5
From 2y + 5z = −4 and y = z + 5:  2z + 10 + 5z = −4 → z = −2, y = 3, x = 6 − 3 + 2 = 5
Solution (x, y, z) = (5, 3, −2); the coefficient matrix has rank 3, so it is unique.
Worked numerical — rank
[[1,2,3],[4,5,6],[7,8,9]]: R2 − 4R1 = (0,−3,−6), R3 − 7R1 = (0,−6,−12) = 2·(R2 − 4R1) → only 2 independent rows → rank 2, det = 0.

Eigenvalues and eigenvectors 🟢 Core

λ is an eigenvalue of A if Ax = λx for some x ≠ 0, i.e. det(A − λI) = 0 (the characteristic equation).

  • Sum of eigenvalues = trace (sum of diagonal); product of eigenvalues = det(A).
  • Triangular (and diagonal) matrices: eigenvalues are the diagonal entries.
  • Eigenvalues of Aᵏ are λᵏ, of A⁻¹ are 1/λ, of A + cI are λ + c, of Aᵀ are the same as A.
  • Cayley–Hamilton: every matrix satisfies its own characteristic equation.
  • Symmetric real matrices: all eigenvalues real, eigenvectors for distinct eigenvalues orthogonal. Eigenvectors for distinct eigenvalues are linearly independent; n distinct eigenvalues ⇒ diagonalisable.
  • A singular matrix has 0 as an eigenvalue.
Worked numerical — 2×2
A = [[4,1],[2,3]]: trace 7, det 10 → λ² − 7λ + 10 = 0 → λ = 5 and 2. Check: 5 + 2 = 7 ✓, 5 × 2 = 10 ✓.
Worked numerical — function of a matrix
A = [[2,0,0],[1,3,0],[4,5,6]] is lower triangular, so λ = 2, 3, 6. Then A² + I has eigenvalues 4+1, 9+1, 36+1 = 5, 10, 37, so det(A² + I) = 5·10·37 = 1850, and trace(A²) = 4 + 9 + 36 = 49.

LU decomposition 🟢 Core

A square matrix (with non-zero pivots) factors as A = LU, with L lower-triangular (1s on the diagonal) and U upper-triangular. Solve Ax = b by forward substitution (Ly = b) then back substitution (Ux = y). Cost: about (2/3)n³ operations versus much more for computing the inverse.

3. Calculus

Limits, continuity, differentiability, maxima and minima, series, and the definite integrals that come up in GATE.

Standard limits 🟢 Core · limits

lim (x→0) sin x / x = 1
lim (x→0) tan x / x = 1
lim (x→0) (1 − cos x)/x² = 1/2
lim (x→0) (eˣ − 1)/x = 1
lim (x→0) ln(1+x)/x = 1
lim (x→∞) (1 + 1/x)ˣ = e
lim (x→∞) (1 + a/x)ˣ = eᵃ
lim (x→0) (1 + x)^(1/x) = e
lim (x→∞) xⁿ / eˣ = 0
lim (x→∞) ln x / x = 0

L'Hôpital's rule: if f/g gives 0/0 or ∞/∞, then lim f/g = lim f'/g' (when the latter exists). Other indeterminate forms (0·∞, ∞−∞, 1∞, 0⁰, ∞⁰) are first rewritten into a quotient. Taylor expansion also works: eˣ = 1 + x + x²/2! + …, sin x = x − x³/3! + …, cos x = 1 − x²/2! + ….

Worked numerical
lim (x→0) (eˣ − 1 − x)/x² :  0/0 → (eˣ − 1)/(2x) → 0/0 → eˣ/2 → 1/2
lim (x→∞) (1 + 2/x)ˣ = e²

Continuity and differentiability 🟢 Core

  • f is continuous at a if limx→a f(x) = f(a). Differentiable ⇒ continuous; the converse is false.
  • f(x) = |x| is continuous everywhere but not differentiable at 0 (a corner); f(x) = x1/3 is continuous but has an infinite slope at 0.
  • Intermediate value theorem: a continuous f on [a,b] takes every value between f(a) and f(b). Extreme value theorem: a continuous f on a closed interval attains a maximum and a minimum.

Mean value theorems 🟢 Core

  • Rolle: f continuous on [a,b], differentiable on (a,b), f(a) = f(b) ⇒ some c with f'(c) = 0.
  • Lagrange (MVT): some c ∈ (a,b) with f'(c) = (f(b) − f(a)) / (b − a).
Worked numerical
f(x) = x² on [1, 3]: slope of the chord = (9 − 1)/2 = 4, and f'(c) = 2c = 4 → c = 2.

Maxima and minima 🟢 Core

Critical points: f'(x) = 0 (or undefined). Second-derivative test: f'' > 0 → local min, f'' < 0 → local max, f'' = 0 → inconclusive. For the absolute max/min on a closed interval, compare critical values and the endpoint values.

Worked numerical
Q: f(x) = 2x³ − 9x² + 12x + 5 on [0, 3]. Find the local and absolute extrema.
A: f'(x) = 6x² − 18x + 12 = 6(x−1)(x−2) → x = 1, 2. f''(x) = 12x − 18: f''(1) = −6 (local max), f''(2) = 6 (local min). 
f(0) = 5     f(1) = 10 (local max)     f(2) = 9 (local min)     f(3) = 14
Absolute maximum on [0,3] = 14 (at the endpoint x = 3)   Absolute minimum = 5 (at x = 0)

Integration 🟢 Core

  • Fundamental theorem: ∫ab f = F(b) − F(a). By parts: ∫u dv = uv − ∫v du.
  • Odd function over [−a, a]: integral = 0. Even function: 2∫0a.
  • Wallis: ∫0π/2 sinnx dx for odd n = (n−1)(n−3)…2 / (n(n−2)…3).
  • Improper: ∫1∞ 1/xp dx converges iff p > 1; ∫01 1/xp dx converges iff p < 1. ∫0∞ e−x dx = 1.
Worked numerical
∫₀¹ x eˣ dx = [x eˣ − eˣ]₀¹ = (e − e) − (0 − 1) = 1
∫₀^(π/2) sin³x dx = 2/3          ∫₀^π sin x dx = 2

Series 🟡 Extension · convergence tests are not an explicit 2027 item

  • Geometric: Σ a·rⁿ converges iff |r| < 1, to a/(1−r). Σn≥0 (1/2)ⁿ = 2.
  • p-series: Σ 1/nᵖ converges iff p > 1 (so the harmonic series Σ 1/n diverges).
  • Ratio test: L = lim |an+1/an|; converges if L < 1, diverges if L > 1, inconclusive at 1. A convergent series must have terms → 0 (converse false).
  • Alternating series with decreasing terms → 0 converges (Leibniz).

L’Hôpital’s rule and Taylor series 🔵 High-Yield · used to evaluate limits; not named in 2027

  • L’Hôpital: if f/g gives 0/0 or ∞/∞ at a point, then lim f/g = lim f′/g′ provided the latter limit exists; repeat if the form persists. Rewrite 0·∞ as a quotient and ∞ − ∞ as a single fraction first.
  • Maclaurin series: eˣ = 1 + x + x²/2! + x³/3! + … · sin x = x − x³/3! + x⁵/5! − … · cos x = 1 − x²/2! + x⁴/4! − … · ln(1 + x) = x − x²/2 + x³/3 − … (|x| < 1) · 1/(1 − x) = 1 + x + x² + … (|x| < 1).
Worked numerical
Q: Evaluate limx→0 (sin x − x)/x³ and limx→0 (eˣ − 1 − x)/x².
A: Using series: sin x − x = −x³/6 + …, so the first limit is −1/6. Also eˣ − 1 − x = x²/2 + …, so the second is 1/2. (L’Hôpital agrees: three differentiations give (−cos x)/6 → −1/6.) Also lim x·ln x = 0 as x → 0⁺, because a power beats a logarithm.

Improper integrals, Gamma and Beta 🟡 Extension · not an explicit 2027 item

  • p-test: ∫₁^∞ x−p dx converges iff p > 1; ∫₀¹ x−p dx converges iff p < 1. ∫₀^∞ e−x dx = 1.
  • Gamma: Γ(n) = ∫₀^∞ xn−1 e−x dx, with Γ(n + 1) = n·Γ(n), so Γ(n + 1) = n! for integers, and Γ(½) = √π.
  • Beta: B(m, n) = ∫₀¹ xm−1(1 − x)n−1 dx = Γ(m)Γ(n)/Γ(m + n). Example: B(2, 3) = (1!·2!)/4! = 1/12.

4. Probability & Statistics

From conditional probability and Bayes' rule to the standard distributions and their means and variances.

Foundations 🟢 Core · conditional probability, Bayes

  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B). P(Aᶜ) = 1 − P(A).
  • Conditional: P(A|B) = P(A ∩ B)/P(B). Independent iff P(A ∩ B) = P(A)P(B). Mutually exclusive events with non-zero probability are not independent.
  • Total probability: P(B) = Σ P(B|Ai)P(Ai) over a partition. Bayes: P(Ai|B) = P(B|Ai)P(Ai) / P(B).
Worked numerical — Bayes
Q: A disease affects 1% of people. A test is positive for 99% of sick people and for 5% of healthy people. If someone tests positive, what is the probability they are sick?
A: 
P(+) = 0.01·0.99 + 0.99·0.05 = 0.0099 + 0.0495 = 0.0594
P(sick | +) = 0.0099 / 0.0594 = 1/6 ≈ 0.167
Even with a very accurate test, a rare condition gives mostly false positives.
Worked numerical — two dice
P(sum = 7) = 6/36 = 1/6. Given that at least one die shows 6 (11 outcomes), P(sum ≥ 10) = favourable {(4,6),(6,4),(5,6),(6,5),(6,6)} = 5/11. Expected maximum of two dice = 161/36.

Random variables 🟢 Core

  • E[X] = Σ x·p(x) (or ∫ x f(x) dx). Linearity always holds: E[X + Y] = E[X] + E[Y], even for dependent X, Y.
  • Var(X) = E[X²] − (E[X])². Var(aX + b) = a²Var(X). For independent X, Y: Var(X + Y) = Var(X) + Var(Y).
  • Cov(X,Y) = E[XY] − E[X]E[Y]; independent ⇒ Cov = 0 (converse false). Correlation ρ ∈ [−1, 1].
  • Chebyshev: P(|X − μ| ≥ kσ) ≤ 1/k². Markov: P(X ≥ a) ≤ E[X]/a for X ≥ 0.
  • Expected number of fixed points of a random permutation = 1 (for any n). Expected tosses of a fair coin until the first head = 2.

Descriptive statistics 🟢 Core · mean, median, mode, standard deviation

Worked numerical — data {2, 3, 5, 7, 8}
mean = 25/5 = 5      median = 5 (middle value)
deviations: −3, −2, 0, 2, 3  →  squares sum = 26
population variance = 26/5 = 5.2        sample variance = 26/4 = 6.5

For a right-skewed distribution mean > median > mode; for a symmetric one they coincide. Sample variance divides by n − 1 (unbiased); population variance divides by n.

PMF, PDF and CDF 🟢 Core · random variables

Every CDF is non-decreasing, runs from 0 to 1, and P(a < X ≤ b) = F(b) − F(a). A density can exceed 1 (only its integral must equal 1); a probability cannot.

Worked numerical
Q: X has density f(x) = kx on [0, 2] and 0 elsewhere. Find k, the CDF, P(X > 1), E[X] and Var(X).
A: ∫₀² kx dx = 2k = 1, so k = 1/2. CDF: F(x) = x²/4 on [0, 2]. P(X > 1) = 1 − F(1) = 1 − 1/4 = 3/4. E[X] = ∫₀² x·(x/2) dx = 8/6 = 4/3. E[X²] = ∫₀² x²·(x/2) dx = 2, so Var(X) = 2 − 16/9 = 2/9.

Joint and marginal distributions 🔵 High-Yield · supports covariance / independence questions

  • The marginal distribution comes from summing (or integrating) the joint over the other variable: pX(x) = Σy p(x, y).
  • X and Y are independent iff p(x, y) = pX(x)·pY(y) for every pair. One failing cell is enough to show dependence.
Worked numerical
Q: P(X,Y): (0,0) = 0.1, (0,1) = 0.3, (1,0) = 0.2, (1,1) = 0.4. Find the marginals, test independence and compute Cov(X, Y).
A: P(X=0) = 0.4, P(X=1) = 0.6; P(Y=0) = 0.3, P(Y=1) = 0.7. Independence would need p(0,0) = 0.4 × 0.3 = 0.12, but p(0,0) = 0.1, so they are dependent. E[XY] = P(X=1, Y=1) = 0.4; E[X]E[Y] = 0.6 × 0.7 = 0.42; Cov = 0.4 − 0.42 = −0.02.

Normal distribution and z-scores 🟢 Core

Standardise: if X ~ N(μ, σ²) then Z = (X − μ)/σ ~ N(0, 1). Use Φ(z) = P(Z ≤ z) with the symmetry Φ(−z) = 1 − Φ(z). Useful values: Φ(0) = 0.5, Φ(1) = 0.8413, Φ(1.5) = 0.9332, Φ(1.96) = 0.9750, Φ(2) = 0.9772. The central 95% lies within ±1.96σ.
Worked numerical
Q: X ~ N(50, 100). Find P(X > 60) and P(40 < X < 65).
A: σ = 10. P(X > 60): z = 1, so 1 − Φ(1) = 1 − 0.8413 = 0.1587. P(40 < X < 65): z from −1 to 1.5, so Φ(1.5) − Φ(−1) = 0.9332 − 0.1587 = 0.7745.

Hypergeometric distribution 🟡 Extension · not among the listed distributions

Drawing n items without replacement from N items of which K are “successes”: P(X = k) = C(K, k)·C(N − K, n − k) / C(N, n), with mean n·K/N. Compare the binomial, which assumes with replacement (independent trials) and has the same mean n·p but a larger variance.

Worked numerical
Q: A box has 20 parts, 5 of them defective. Four are drawn without replacement. Find P(exactly 1 defective) and the expected number of defectives.
A: P = C(5,1)·C(15,3)/C(20,4) = 5 × 455 / 4845 ≈ 0.4696. Mean = 4 × 5/20 = 1.

🧮 Representative GATE-style Worked Problems

Problem 1 · Probability

Let X~Binomial(10,0.2). Find E[X] and Var(X).

Method: E=np and Var=np(1−p).

Answer: E[X]=2, Var(X)=1.6.

Problem 2 · Linear Algebra

If A is a 3×3 matrix with characteristic polynomial λ³−6λ²+11λ−6, find A³−6A²+11A.

Method: Apply Cayley–Hamilton directly: p(A)=0.

Answer: 6I.

Problem 3 · Recurrence

T(n)=2T(n/2)+n. Determine the asymptotic order.

Method: Master theorem: a=2,b=2,n^{log₂2}=n and f(n)=n.

Answer: Θ(n log n).

Problem 4 · Graph

An undirected graph has 10 vertices and 9 edges and is connected. What can you conclude?

Method: A connected graph with n−1 edges is a tree.

Answer: It is a tree; hence every edge is a bridge.

Problem 5 · Probability

X is exponential with rate 2. Find P(X>3).

Method: Survival function P(X>t)=e^{−λt}.

Answer: e−6.

7. GATE-Level Solved Problems

The 58 quiz questions above check fundamentals. These are heavier, multi-step problems in GATE style — every step shown, and every answer machine-verified.
Q1 · Propositional logic — counting models
How many assignments of (p, q, r) satisfy (p → q) ∧ (q → r) ∧ (r → p)?
  1. 1
  2. 2
  3. 3
  4. 4
The three implications form a cycle p → q → r → p.
If any variable is true, truth propagates around the cycle, making all three true.
If any is false, falsity propagates backwards, making all three false.
So p = q = r: the only satisfying assignments are 000 and 111.

Correct: Option 2 — 2 assignments.

Q2 · Counting relations
On a set with 3 elements, how many relations are antisymmetric?
  1. 64
  2. 216
  3. 512
  4. 729
Diagonal pairs (a,a): no restriction → each in or out → 2³ = 8 choices.
Each of the C(3,2) = 3 unordered pairs {a,b}: contains neither (a,b) nor (b,a), or only (a,b), or only (b,a)
   → 3 choices each (both together is forbidden) → 3³ = 27.
Total = 8 × 27 = 216   (formula: 2ⁿ · 3^(n(n−1)/2); verified by enumerating all 512 relations)

Correct: Option 2 — 216.

Q3 · Cyclic groups
For the cyclic group Z₁₂ under addition mod 12, how many subgroups does it have, and how many generators?
  1. 4 subgroups, 6 generators
  2. 6 subgroups, 4 generators
  3. 12 subgroups, 4 generators
  4. 6 subgroups, 6 generators
A cyclic group of order n has exactly one subgroup for every divisor of n.
Divisors of 12: 1, 2, 3, 4, 6, 12 → 6 subgroups.
Generators are elements coprime to 12: {1, 5, 7, 11} → φ(12) = 4.

Correct: Option 2 — 6 subgroups and 4 generators.

Q4 · Inclusion–exclusion
How many integers from 1 to 1000 are divisible by none of 2, 3 and 5?
  1. 200
  2. 266
  3. 333
  4. 367

by 6: 166   by 10: 100   by 15: 66      by 30: 33
|A ∪ B ∪ C| = 500 + 333 + 200 − 166 − 100 − 66 + 33 = 734
Neither = 1000 − 734 = 266

Q5 · Linear recurrence
a₀ = 1, a₁ = 4 and aₙ = 5aₙ₋₁ − 6aₙ₋₂. What is a₅?
  1. 146
  2. 454
  3. 1394

Q6 · Chromatic polynomial
In how many ways can the vertices of a 5-cycle C₅ be properly coloured using 3 colours?
  1. 18
  2. 24
  3. 30
  4. 48
P(Cₙ, k) = (k − 1)ⁿ + (−1)ⁿ (k − 1)
P(C₅, 3) = 2⁵ + (−1)⁵·2 = 32 − 2 = 30        (brute-force enumeration agrees)

Correct: Option 3 — 30.

Q7 · Planar graph faces
A connected planar graph has 10 vertices and every face is bounded by exactly 3 edges. How many faces does it have?
  1. 14
  2. 15
  3. 16
  4. 18
Each face has 3 edges and each edge borders 2 faces: 3f = 2e → e = 3f/2.
Euler: v − e + f = 2 → 10 − 3f/2 + f = 2 → f/2 = 8 → f = 16, e = 24 (= 3v − 6 ✔).

Correct: Option 3 — 16 faces.

Q8 · Eigenvalues of a function of a matrix
A = [[2,0,0],[1,3,0],[4,5,6]]. What is det(A² + I)?
  1. 1850
  2. 1296
  3. 180
  4. 2701
A is lower triangular → eigenvalues are the diagonal entries 2, 3, 6.
A² + I has eigenvalues λ² + 1 = 5, 10, 37.
det = product of eigenvalues = 5 × 10 × 37 = 1850          (numerical check: 1850)

Correct: Option 1 — 1850.

Q9 · Absolute extremum on a closed interval
What is the maximum value of f(x) = 2x³ − 9x² + 12x + 5 on the interval [0, 3]?
  1. 9
  2. 10
  3. 14
  4. 5
f'(x) = 6(x − 1)(x − 2) → critical points x = 1 (local max, f = 10) and x = 2 (local min, f = 9)
Compare with endpoints: f(0) = 5, f(3) = 54 − 81 + 36 + 5 = 14
Absolute maximum on [0, 3] = 14 (at x = 3). The local maximum 10 is not the absolute one.

Correct: Option 3 — 14.

Q10 · Bayes' theorem
1% of a population is infected. A test detects 99% of infected people and gives a false positive for 5% of uninfected people. A person tests positive. The probability that they are infected is:
  1. 0.99
  2. 1/6
  3. 0.5
  4. 1/21
P(+) = 0.01·0.99 + 0.99·0.05 = 0.0099 + 0.0495 = 0.0594
P(infected | +) = 0.0099 / 0.0594 = 1/6 ≈ 0.167

Correct: Option 2 — 1/6.

Q11 · Limits — Taylor series vs L'Hôpital
The value of limx→0 (sin x − x cos x) / x³ is:
  1. 0
  2. 1/6
  3. 1/3
  4. 1/2
Form 0/0 — expand both terms:
   sin x   = x − x³/6 + x⁵/120 − …
   x cos x = x − x³/2 + x⁵/24  − …
   numerator = (−1/6 + 1/2) x³ + O(x⁵) = x³/3 + O(x⁵)
   limit = 1/3

Check with L'Hôpital (3 rounds):
   N'  = cos x − cos x + x sin x = x sin x      D' = 3x²    → (x sin x)/(3x²) = (sin x)/(3x) → 1/3 ✔

Correct: Option 3 — 1/3.

Q12 · LU decomposition (Doolittle)
For A = [[2,1,1],[4,3,3],[8,7,9]] written as A = LU with L unit lower-triangular, what are l₃₂, u₃₃ and det(A)?
  1. l₃₂ = 3, u₃₃ = 2, det = 4
  2. l₃₂ = 2, u₃₃ = 2, det = 4
  3. l₃₂ = 3, u₃₃ = 4, det = 8
  4. l₃₂ = 3, u₃₃ = 2, det = 8
Row operations (this is Gaussian elimination, remembering the multipliers):
R2 ← R2 − 2·R1 :  [0, 1, 1]      multiplier l₂₁ = 2
R3 ← R3 − 4·R1 :  [0, 3, 5]      multiplier l₃₁ = 4
R3 ← R3 − 3·R2 :  [0, 0, 2]      multiplier l₃₂ = 3

L = | 1 0 0 |      U = | 2 1 1 |
    | 2 1 0 |          | 0 1 1 |
    | 4 3 1 |          | 0 0 2 |

det A = det L · det U = 1 × (2·1·2) = 4      (product of U's diagonal)
Check: row 3 of LU = 4·[2,1,1] + 3·[0,1,1] + [0,0,2] = [8, 7, 9] ✔

Correct: Option 1 — l₃₂ = 3, u₃₃ = 2, det A = 4.

Q13 · Hasse diagram and lattice properties
For the poset (D₃₆, |) — the divisors of 36 under divisibility — how many edges does the Hasse diagram have, and which statement is true?
  1. 12 edges; a Boolean algebra
  2. 12 edges; a distributive lattice that is not complemented
  3. 10 edges; a distributive lattice that is not complemented
  4. 12 edges; a lattice that is not distributive
D₃₆ = {1, 2, 3, 4, 6, 9, 12, 18, 36}  — 9 elements.   36 = 2² · 3², so D₃₆ ≅ chain(0,1,2) × chain(0,1,2)
(a 3 × 3 grid, with element 2^a·3^b ↔ (a, b)).

Covering pairs (an edge exists only when b = a·prime):
   1–2, 1–3, 2–4, 2–6, 3–6, 3–9, 4–12, 6–12, 6–18, 9–18, 12–36, 18–36   → 12 edges

                 36
               /    \
             12      18
            /  \    /  \
           4    6       9
            \  / \    /
             2     3
               \  /
                1

Lattice: every pair has gcd (meet) and lcm (join).   Distributive: product of chains.
Boolean algebra needs 2ⁿ elements (9 is not a power of 2), and complements fail:
   2 would need x with gcd(2,x) = 1 and lcm(2,x) = 36 → none.   So NOT complemented.
(Compare D₃₀ = 2·3·5: 8 elements, squarefree ⇒ Boolean.)

Correct: Option 2 — 12 edges; distributive but not complemented.

Q14 · System of linear equations — rank and parameters
Consider x + y + z = 1, x + 2y + 3z = 2, x + 3y + kz = m. For which (k, m) does the system have (a) a unique solution, (b) no solution, (c) infinitely many solutions?
  1. (a) k ≠ 5; (b) k = 5, m ≠ 3; (c) k = 5, m = 3
  2. (a) k ≠ 5; (b) k = 5, m = 3; (c) k = 5, m ≠ 3
  3. (a) k = 5; (b) k ≠ 5; (c) never
  4. (a) k ≠ 3; (b) k = 3, m ≠ 5; (c) k = 3, m = 5
Coefficient matrix A = [[1,1,1],[1,2,3],[1,3,k]].
   det A = 1(2k − 9) − 1(k − 3) + 1(3 − 2) = 2k − 9 − k + 3 + 1 = k − 5.

(a) k ≠ 5 → det ≠ 0 → rank A = 3 = rank [A|b] → UNIQUE solution for every m.
k = 5: reduce the augmented matrix  R2 − R1 → (0,1,2 | 1),  R3 − R1 → (0,2,4 | m − 1),  then R3 − 2·R2 → (0,0,0 | m − 3).
   rank A = 2.
(b) m ≠ 3 → the last row reads 0 = m − 3 ≠ 0 → rank [A|b] = 3 > rank A → NO solution (inconsistent).
(c) m = 3 → rank [A|b] = 2 = rank A < 3 unknowns → INFINITELY many solutions (one free variable: z = t, y = 1 − 2t, x = t).

Rouché–Capelli rule:  rank A = rank [A|b] = n → unique;  rank A = rank [A|b] < n → infinitely many (n − rank free variables);  rank A < rank [A|b] → none.
Check: ranks were computed symbolically — (k,m) = (5,3): ranks 2,2; (5,4): ranks 2,3; (6,0): ranks 3,3 — and the row-reduced form has pivots only when k ≠ 5.
Trap: at k = 5 the answer depends on m; many students stop after finding det = 0 and wrongly call the system inconsistent.

Correct: Option 1 — unique if k ≠ 5; none if k = 5 and m ≠ 3; infinitely many if k = 5 and m = 3.

Q15 · Cayley–Hamilton — inverse and higher powers of a matrix
A = [[1, 2], [3, 4]]. Using the Cayley–Hamilton theorem, find A⁻¹ and write A⁴ in the form pA + qI.
  1. A⁻¹ = (A − 5I)/2 = [[−2, 1], [1.5, −0.5]]; A⁴ = 145A + 54I
  2. A⁻¹ = (A − 5I)/2 = [[−2, 1], [1.5, −0.5]]; A⁴ = 29A + 10I
  3. A⁻¹ = (5I − A)/2 = [[2, −1], [−1.5, 0.5]]; A⁴ = 145A + 54I
  4. A⁻¹ = (A + 5I)/2 = [[3, 1], [1.5, 4.5]]; A⁴ = 25A + 4I
Characteristic polynomial: λ² − (trace)λ + det = λ² − 5λ − 2     (trace = 1 + 4 = 5, det = 4 − 6 = −2).
Cayley–Hamilton: every matrix satisfies its own characteristic equation →  A² − 5A − 2I = 0,  i.e.  A² = 5A + 2I.

Inverse: multiply A² − 5A − 2I = 0 by A⁻¹ →  A − 5I − 2A⁻¹ = 0  →  A⁻¹ = (A − 5I)/2 = [[−4, 2], [3, −1]] / 2 = [[−2, 1], [1.5, −0.5]].
   Check: A·A⁻¹ = [[1(−2) + 2(1.5), 1(1) + 2(−0.5)], [3(−2) + 4(1.5), 3(1) + 4(−0.5)]] = [[1, 0], [0, 1]] ✔

Higher powers: reduce with A² = 5A + 2I each time.
   A³ = A·A² = 5A² + 2A = 5(5A + 2I) + 2A = 27A + 10I
   A⁴ = A·A³ = 27A² + 10A = 27(5A + 2I) + 10A = 145A + 54I
   Check: 145A + 54I = [[145 + 54, 290], [435, 580 + 54]] = [[199, 290], [435, 634]], which equals A⁴ computed by direct multiplication.

Check: the characteristic polynomial, A⁻¹, A³ = 27A + 10I and A⁴ = 145A + 54I were verified symbolically.
Trap: (5I − A)/2 is −A⁻¹ (wrong sign); and A⁴ is NOT 29A + 10I — that is 5A³ + 2A² mis-reduced; every reduction must use A² = 5A + 2I.

Correct: Option 1 — A⁻¹ = (A − 5I)/2 and A⁴ = 145A + 54I.

Q16 · Joint distribution — marginals, covariance and independence
X ∈ {0, 1} and Y ∈ {0, 1, 2} have joint probabilities P(0,0) = 1/8, P(0,1) = 1/8, P(0,2) = 1/4, P(1,0) = 1/4, P(1,1) = 1/8, P(1,2) = 1/8. Find E[X], E[Y], Cov(X, Y) and say whether X and Y are independent.
  1. 1/2, 1, −1/8, not independent
  2. 1/2, 1, 0, independent
  3. 1/2, 1, 1/8, not independent
  4. 1/4, 1, −1/8, not independent
Marginals (add along rows and columns):
   P(X=0) = 1/8 + 1/8 + 1/4 = 1/2;   P(X=1) = 1/4 + 1/8 + 1/8 = 1/2
   P(Y=0) = 1/8 + 1/4 = 3/8;   P(Y=1) = 1/8 + 1/8 = 1/4;   P(Y=2) = 1/4 + 1/8 = 3/8      (total 1 ✔)
Expectations:  E[X] = 0·1/2 + 1·1/2 = 1/2;     E[Y] = 0·3/8 + 1·1/4 + 2·3/8 = 1/4 + 3/4 = 1
E[XY] = Σ x·y·P = 1·1·(1/8) + 1·2·(1/8) = 1/8 + 2/8 = 3/8      (only x = 1 and y ≥ 1 contribute)
Cov(X, Y) = E[XY] − E[X]E[Y] = 3/8 − (1/2)(1) = −1/8.

Independence needs P(x, y) = P(x)P(y) for EVERY cell: P(0,0) = 1/8 but P(X=0)P(Y=0) = (1/2)(3/8) = 3/16 ≠ 1/8 → NOT independent (consistent with Cov ≠ 0).
Extras: Var(Y) = E[Y²] − 1 = (1/4 + 4·3/8) − 1 = 3/4;  P(Y=2 | X=0) = (1/4)/(1/2) = 1/2;  E[Y | X=1] = (1/8 + 2/8)/(1/2) = 3/4.
Check: all of these were recomputed with exact fractions.
Trap: Cov = 0 does NOT prove independence in general; here the non-zero covariance already proves dependence, and a single failed cell is enough.

Correct: Option 1 — E[X] = 1/2, E[Y] = 1, Cov(X, Y) = −1/8, so X and Y are not independent.

Q17 · Normal distribution — z-scores and the 68–95–99.7 rule
Marks are normally distributed with mean 70 and standard deviation 10. Using Φ(1) = 0.8413, Φ(1.5) = 0.9332 and Φ(2) = 0.9772, find P(X > 85) and P(50 < X < 90).
  1. 0.0668 and 0.9544
  2. 0.0668 and 0.6826
  3. 0.1587 and 0.9544
  4. 0.9332 and 0.9544
Standardise:  Z = (X − μ)/σ  with μ = 70, σ = 10.
P(X > 85):  z = (85 − 70)/10 = 1.5   →   P(Z > 1.5) = 1 − Φ(1.5) = 1 − 0.9332 = 0.0668.
P(50 < X < 90):  z from (50 − 70)/10 = −2 to (90 − 70)/10 = +2
   = Φ(2) − Φ(−2) = Φ(2) − (1 − Φ(2)) = 2Φ(2) − 1 = 2(0.9772) − 1 = 0.9544   (the '95%' rule: within 2σ).
Symmetry rule: Φ(−z) = 1 − Φ(z).  Other bands: within 1σ → 2Φ(1) − 1 = 0.6826; within 3σ → 0.9973.
Check: the exact normal CDF gives 0.06681 and 0.95450.
Trap: forgetting to subtract from 1 for an upper tail (which gives 0.9332), or using 1σ (0.6826) for a ±2σ band.

Correct: Option 1 — P(X > 85) = 0.0668 and P(50 < X < 90) = 0.9544.

Q18 · Gamma and Beta integrals
Evaluate (i) ∫₀^∞ x⁴ e^(−2x) dx and (ii) ∫₀¹ x³ (1 − x)² dx.
  1. 3/4 and 1/60
  2. 3/4 and 1/30
  3. 6 and 1/60
  4. 3/2 and 1/20
Gamma function:  ∫₀^∞ x^(n−1) e^(−ax) dx = Γ(n)/a^n,   Γ(n) = (n − 1)! for integer n,   Γ(1/2) = √π,   Γ(n + 1) = nΓ(n).
Beta function:   ∫₀¹ x^(m−1) (1 − x)^(n−1) dx = B(m, n) = Γ(m)Γ(n)/Γ(m + n).

(i)  x⁴ e^(−2x): n − 1 = 4 → n = 5, a = 2:  Γ(5)/2⁵ = 4!/32 = 24/32 = 3/4.
(ii) x³ (1 − x)²: m = 4, n = 3:  B(4, 3) = Γ(4)Γ(3)/Γ(7) = (3!·2!)/6! = 12/720 = 1/60.
Useful values: ∫₀^∞ e^(−x²) dx = √π/2;  Γ(5/2) = (3/2)(1/2)√π = 3√π/4.
Check: both integrals were evaluated symbolically: 3/4 and 1/60.
Trap: with e^(−2x) the answer is Γ(n)/2^n, not Γ(n); and in the Beta integral the exponents are m − 1 and n − 1, so x³(1 − x)² is B(4, 3), not B(3, 2).

Correct: Option 1 — (i) 3/4 and (ii) 1/60.
