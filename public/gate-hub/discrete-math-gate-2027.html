Syllabus & Scope

For GATE 2027 CS, Discrete Mathematics covers propositional and first-order logic; sets, relations, functions, partial orders and lattices; monoids and groups; graphs (connectivity, matching, colouring); and combinatorics (counting, recurrence relations, generating functions). This page is organized around those official syllabus lines.

1. Logic

🟢 Must RememberImplication

P → Q ≡ ¬P ∨ Q. It is false only when P is true and Q is false.

🧮 Formula / RuleEquivalences

P ↔ Q ≡ (P→Q) ∧ (Q→P); De Morgan: ¬(P∧Q)=¬P∨¬Q, ¬(P∨Q)=¬P∧¬Q.

🟡 Common TrapConverse vs contrapositive

Contrapositive of P→Q is ¬Q→¬P and is equivalent. Converse Q→P is generally not.

⚠️ GATE FavouriteQuantifiers

Negation flips quantifier: ¬∀x P(x) ≡ ∃x ¬P(x), ¬∃x P(x) ≡ ∀x ¬P(x).

An argument is valid iff the premises true can never coexist with a false conclusion, i.e. (premises ∧ ¬conclusion) is unsatisfiable.

🟡 Common TrapTwo fallacies that look like valid rules

Affirming the conclusion: P→Q, Q ⊢ P is invalid. Denying the hypothesis: P→Q, ¬P ⊢ ¬Q is invalid. Counter-example for both: P = F, Q = T makes the premises true and the conclusion false.

🟢 Must RememberNormal forms & counting

CNF = AND of ORs of literals; DNF = OR of ANDs. A formula in CNF is valid iff every clause contains some x and ¬x; a formula in DNF is satisfiable iff some term has no clashing literals. n variables → 2ⁿ truth-table rows and 2^(2ⁿ) different Boolean functions (n = 2 gives 16).

⚠️ GATE FavouriteTranslating English into FOL; free vs bound variables

All S are L: ∀x (S(x)→L(x)). Some S are L: ∃x (S(x)∧L(x)). Using ∧ with ∀ (or → with ∃) is the classic wrong answer. Order matters: ∀x∃y Loves(x,y) = “everybody loves somebody”, while ∃y∀x Loves(x,y) = “somebody is loved by everybody” (much stronger). A variable is bound if a quantifier covers it, otherwise free; a formula with no free variables is a sentence and has a truth value.

✏️ Worked ExampleIs the argument valid?

Premises: if it rains the match is cancelled; the match is not cancelled. Conclusion: it did not rain.

Let R = rain, C = cancelled: R→C, ¬C ⊢ ¬R. This is modus tollens, so the argument is valid. Had the second premise been “the match is cancelled”, the argument would commit the fallacy of affirming the conclusion and be invalid.

🧮 Formula / RuleFunctional completeness

A set of connectives is functionally complete if every Boolean function can be built from it.

⚠️ GATE FavouriteQuantifier distribution — which direction is valid?

∀ distributes over ∧ and ∃ over ∨ exactly: ∀x(P∧Q) ≡ ∀xP ∧ ∀xQ, ∃x(P∨Q) ≡ ∃xP ∨ ∃xQ. For the other pairings only one direction holds:

🟢 Must RememberValid, satisfiable, unsatisfiable

Valid (tautology) = true under every interpretation. Satisfiable = true under at least one. Unsatisfiable (contradiction) = true under none. A is valid ⇔ ¬A is unsatisfiable. A formula can be satisfiable yet not valid (e.g. P → Q). Propositional SAT is NP-complete; validity in first-order logic is undecidable (but semi-decidable).

🟢 Must RememberFree and bound variables

An occurrence of x is bound if it lies inside the scope of a quantifier ∀x or ∃x; otherwise it is free. A quantifier’s scope is the formula that immediately follows it. A formula with no free variables is a sentence (closed formula) and is simply true or false in a given domain; one with free variables is true or false only after the variables are given values. The same letter can be free in one place and bound in another, and a quantified variable can be renamed (∃x Q(x) ≡ ∃z Q(z)) as long as the new name does not clash with a free variable.

Worked example. In ∀x (P(x, y) → ∃z Q(x, z)) ∧ R(x), the ∀x covers only P(x, y) → ∃z Q(x, z), so x is bound there. The final R(x) lies outside that scope, so that x is free; y is free (nothing quantifies it); z is bound by ∃z. Free variables: y and the x in R(x), so the formula is not a sentence.

2. Sets, Relations & Functions

🟢 Must RememberRelation properties

Reflexive: (a,a) for every a. Symmetric: aRb ⇒ bRa. Antisymmetric: aRb and bRa ⇒ a=b. Transitive: aRb and bRc ⇒ aRc.

⚠️ GATE FavouriteEquivalence relation

Exactly: reflexive + symmetric + transitive. Equivalence classes form a partition of the set.

🧮 Formula / RuleFunction composition

If f:A→B and g:B→C, then g∘f:A→C. Composition order matters.

🟡 Common TrapInjective/surjective

Injective concerns distinct inputs having distinct outputs. Surjective means every codomain element is hit. Neither implies the other for finite sets of unequal size.

🟢 Must RememberClosures of a relation

Reflexive closure = R ∪ Δ. Symmetric closure = R ∪ R⁻¹. Transitive closure R⁺ = smallest transitive relation containing R (Warshall’s algorithm, O(n³)). Equivalence closure = take reflexive, symmetric and transitive closure; apply the transitive step last. Example: R = {(1,2),(2,3),(3,4)} has transitive closure with 6 pairs: the three originals plus (1,3), (2,4), (1,4).

⚠️ GATE FavouriteProperties of functions and composition

For finite sets of equal size, injective ⇔ surjective ⇔ bijective. If g∘f is injective then f is injective; if g∘f is surjective then g is surjective. A function has an inverse iff it is bijective. |P(A)| = 2ⁿ, |A×B| = |A||B|.

✏️ Worked ExampleHow many equivalence relations on a 4-element set have exactly 2 classes?

Count partitions into 2 blocks: Stirling number S(4,2) = 7 (four of type 3+1 and three of type 2+2). Adding the other block counts: S(4,1)=1, S(4,3)=6, S(4,4)=1 totals the Bell number 15.

🟢 Must RememberCardinality and countability

Countably infinite (same size as ℕ): ℤ, ℚ, ℕ×ℕ, the set of all finite strings over a finite alphabet, any finite union or product of countable sets, and any subset of a countable set. Uncountable: ℝ, the power set 𝒫(ℕ), the set of all infinite binary strings, the set of all functions ℕ→{0,1} (Cantor's diagonal argument). For any set A, |𝒫(A)| = 2|A| > |A|. Programs (or Turing machines) are finite strings, hence countable, while languages are uncountable — so most languages are not recognised by any machine.

🧮 Formula / RuleComposition, inverse and extra counts for relations

Composition (apply R first, then S): S∘R = {(a,c) : ∃b, aRb and bSc}; (S∘R)⁻¹ = R⁻¹∘S⁻¹. With Boolean matrices MS∘R = MR · MS (Boolean product). R is transitive iff R∘R ⊆ R; the transitive closure is R ∪ R² ∪ … ∪ Rⁿ. On an n-element set: reflexive and antisymmetric = 3n(n−1)/2 (27 for n = 3); symmetric and antisymmetric = 2ⁿ (subsets of the diagonal); partial orders on 3 labelled elements = 19; transitive relations on 3 elements = 171. Idempotent functions (f∘f = f) on n points: Σk C(n,k)·kn−k (n = 3 gives 3 + 6 + 1 = 10).

🟡 Common TrapUnions and intersections of equivalence relations

The intersection of equivalence relations is an equivalence relation, but the union need not be: {1~2} ∪ {2~3} lacks (1,3), so transitivity fails. The smallest equivalence relation containing both is the transitive closure of the union.

3. Partial Orders & Lattices

🟢 Must RememberPartial order

A relation that is reflexive, antisymmetric and transitive. A poset is (P,≤).

⚠️ GATE FavouriteHasse diagram

Represent the cover relation only; omit reflexive and transitive edges. Read minimal/maximal elements from the diagram carefully.

🟡 Common TrapMinimal vs least

A least element is ≤ every element and is unique if it exists. A poset may have multiple minimal elements without having a least element.

💡 ShortcutFinite lattice check

Every pair must have both a unique least upper bound (join) and a unique greatest lower bound (meet).

🟢 Must RememberBounds, chains and antichains

An upper bound of a subset S is an element ≥ every member of S; the least upper bound (join) is the smallest such bound, and the greatest lower bound (meet) is defined dually. A chain is a set of pairwise comparable elements and an antichain a set of pairwise incomparable ones. Dilworth: the minimum number of chains needed to cover a finite poset equals the size of its largest antichain.

🧮 Formula / RuleFacts about the divisor lattice Dn (n = p₁^a₁ · p₂^a₂ · …)

Elements: ∏(aᵢ+1) (360 = 2³·3²·5 has 24 divisors). Meet = gcd, join = lcm. Dn is always distributive; it is a Boolean algebra iff n is square-free, and then it has 2ᵏ elements for k primes. Hasse-diagram edges = Σᵢ aᵢ · ∏ⱼ≠ᵢ (aⱼ+1): D12 gives 2·2 + 1·3 = 7, D36 gives 2·3 + 2·3 = 12, D30 gives 12 (a cube).

🟡 Common TrapLattice types

Bounded = has top and bottom (every finite lattice is). Complemented = every element has a complement (x∧y = ⊥ and x∨y = ⊤). Distributive = x∧(y∨z) = (x∧y)∨(x∧z). A lattice is distributive iff it contains no copy of the diamond M₃ or pentagon N₅. A Boolean algebra is a complemented distributive lattice, so it has 2ᵏ elements. A complemented lattice need not be distributive.

✏️ Worked ExampleIs the poset ({1,2,3,6,12,18}, divisibility) a lattice?

Check pairs that might fail: lcm(12,18) = 36, which is not in the set, so 12 and 18 have no upper bound at all. Hence not a lattice. A common mistake is to test only gcd; both meet and join must exist for every pair.

🧮 Formula / RuleChains, antichains and Dilworth in divisor and subset posets

Dilworth: minimum number of chains covering a poset = size of the largest antichain; Mirsky (dual): minimum number of antichains = length of the longest chain. In Dn with n = p₁^a₁·p₂^a₂·…: longest chain has Σaᵢ + 1 elements; the number of maximal chains = (Σaᵢ)! / ∏aᵢ! (D36: 4!/(2!2!) = 6; D360: 6!/(3!2!1!) = 60). In the subset lattice 𝒫(n): n! maximal chains and largest antichain C(n, ⌊n/2⌋) (Sperner). For divisibility on {1,…,12} the largest antichain is {7,…,12} (size 6), so 6 chains suffice and are needed.

🟡 Common TrapDistributive, complemented and the forbidden sublattices

A lattice is distributive iff it has no sublattice isomorphic to the diamond M₃ or the pentagon N₅ (N₅: 0 < a < c < 1 and 0 < b < 1; there c∧(a∨b) = c but (c∧a)∨(c∧b) = a). Both are complemented lattices that are not distributive; in N₅ the element b has two complements (a and c). In a distributive lattice complements are unique, so Boolean algebras have unique complements. A chain with more than two elements is distributive but not complemented.

4. Monoids & Groups

🟢 Must RememberHierarchy

Semigroup = associative. Monoid = associative + identity. Group = monoid + inverse for every element.

⚠️ GATE FavouriteGroup facts

Identity is unique; inverse of each element is unique. In a finite group, cancellation holds.

🟡 Common TrapClosure is separate

Associativity alone does not make a structure a semigroup. Verify closure under the operation too.

🟢 Must RememberCyclic groups (order n, generator g)

The number of generators is φ(n). There is exactly one subgroup per divisor of n. The number of elements of order d (for d | n) is φ(d). In Z₁₂: 4 generators (1, 5, 7, 11); the elements of order 4 are 3 and 9 (φ(4) = 2). The order of a in Zn is n / gcd(a, n).

⚠️ GATE FavouriteLagrange and its consequences

|H| divides |G| for every subgroup H, so the order of every element divides |G|; a group of prime order is cyclic; the converse of Lagrange is false (A₄ has order 12 but no subgroup of order 6). If a² = e for all a then G is abelian; every group of even order has an element of order 2. Groups of order 4: Z₄ and the Klein four-group; order 6: Z₆ and S₃.

💡 ShortcutSubgroup test

A non-empty H ⊆ G is a subgroup iff a, b ∈ H ⇒ a·b⁻¹ ∈ H. For a finite H it is enough that H is closed under the operation.

🟢 Must RememberPermutation groups

Sn has n! elements and is non-abelian for n ≥ 3. Write permutations as disjoint cycles: the order is the lcm of the cycle lengths, and fk only depends on k mod order (for (1 2 3)(4 5), f100 = f4 = (1 2 3)). A k-cycle is even iff k is odd; parity is multiplicative; An (even permutations) has n!/2 elements and is normal in Sn. Elements with cycle type having mk cycles of length k: n! / ∏(kmk·mk!). In S₅ the orders are 1,2,3,4,5,6 with max 6 (type 3+2, 20 elements); in S₄ there are 8 elements of order 3; S₇ has max order 12 (type 4+3). A₄ has order 12 but no subgroup of order 6.

🧮 Formula / RuleNormal subgroups, homomorphisms and direct products

H is normal if gHg⁻¹ = H for all g; every subgroup of index 2 is normal and every kernel is normal. First isomorphism theorem: G/ker f ≅ im f, so |im f| = |G|/|ker f|. Number of homomorphisms Zm → Zn = gcd(m, n) (f(1) must have order dividing m). Zm×Zn is cyclic iff gcd(m,n) = 1; the order of (a,b) in a product is lcm(|a|,|b|). Groups of order 4: Z₄, Klein V₄; order 6: Z₆, S₃; order 8: five groups.

🧮 Formula / RuleThe group of units Zn*

Zn* = {a : gcd(a,n) = 1} under multiplication mod n has φ(n) elements. It is cyclic iff n = 1, 2, 4, pk or 2pk (p an odd prime). So Z₉*, Z₁₀*, Z₁₈* are cyclic, while Z₈* and Z₁₂* are the Klein four-group and Z₁₅* ≅ Z₂×Z₄ (order 8, no element of order 8) are not.

5. Combinatorics

🧮 Formula / RulePermutations & combinations

nPr = n!/(n-r)!, nCr = n!/[r!(n-r)!], and nCr=nC(n-r).

⚠️ GATE FavouriteInclusion–Exclusion

For two sets: |A∪B|=|A|+|B|-|A∩B|. For many sets, alternate signs across intersections.

💡 ShortcutAt least one

Often easier as total − none. For independent repeated choices, compute the complement first when the event is “at least one”.

🟡 Common TrapPigeonhole

If n objects are placed into k boxes and n>k, at least one box has ≥2 objects. General form: some box has at least ceil(n/k) objects.

✏️ Worked Example5 men and 3 women in a row, no two women adjacent

Seat the men first: 5! = 120. They create 6 gaps; choose 3 for the women: C(6,3) = 20; arrange the women: 3! = 6. Total = 120 × 20 × 6 = 14400.

🧮 Formula / RuleCircular arrangements and restricted arrangements

n distinct objects in a circle: (n − 1)!. Two particular objects adjacent: 2·(n − 2)!; not adjacent: (n − 1)! − 2·(n − 2)!. m men and m women alternating: (m − 1)!·m!. Bracelet (flip also allowed): (n − 1)!/2. In a line, use the block method (glue items that must be together) or the gap method: arrange the unrestricted items first, then choose gaps for the restricted ones — r items that may not touch go into C(k + 1, r) of the k + 1 gaps around k other items.

Example: MISSISSIPPI with no two S adjacent: arrange M,I,I,I,I,P,P in 7!/(4!2!) = 105 ways, then pick 4 of the 8 gaps: 105 × C(8,4) = 105 × 70 = 7350.

🟡 Common TrapPigeonhole variants

To guarantee r objects in one of k boxes you need (r − 1)·k + 1 objects (37 people ⇒ 4 share a birth month). Among any n + 1 integers two leave the same remainder mod n. Divisibility form: from {1,…,2n} any n + 1 numbers contain two with one dividing the other — group the numbers by their odd part (there are n groups), because two numbers with the same odd part divide each other. The bound is tight: {n+1,…,2n} has no such pair.

6. Recurrence Relations & Generating Functions

🟢 Must RememberLinear homogeneous recurrence

For constant coefficients, form the characteristic equation. Repeated roots require polynomial factors in n.

🧮 Formula / RuleRepeated root

Root r of multiplicity k contributes (C₀+C₁n+...+Cₖ₋₁n^(k−1))rⁿ.

⚠️ GATE FavouriteParticular solution

For non-homogeneous recurrences, choose an appropriate particular form; if it overlaps a homogeneous root, multiply the trial by the required power of n.

💡 ShortcutGenerating functions

Translate sequence terms into a power series, manipulate algebraically, then extract the coefficient. Keep indexing consistent.

✏️ Worked ExampleNon-homogeneous with an overlapping root

aₙ = 5aₙ₋₁ − 6aₙ₋₂ + 2ⁿ, a₀ = 0, a₁ = 1. Homogeneous roots are 2 and 3. The forcing term 2ⁿ overlaps root 2, so the trial particular solution is C·n·2ⁿ (multiply by n). Substituting gives C = −2. General solution: A·2ⁿ + B·3ⁿ − 2n·2ⁿ; a₀ and a₁ give A = −5, B = 5, so aₙ = 5·3ⁿ − 5·2ⁿ − 2n·2ⁿ (check: a₂ = 45 − 20 − 16 = 9 = 5·1 − 0 + 4).

💡 ShortcutGenerating functions: coins, bounds and parity

Coins of 1, 2, 5: 1/((1−x)(1−x²)(1−x⁵)) — the coefficient of xⁿ is the number of ways to pay n (n = 15 gives 18). A variable with 0 ≤ x ≤ u contributes (1 − xu+1)/(1 − x); an even count contributes 1/(1 − x²) and an odd count x/(1 − x²). Partitions of n into parts of size at most k: ∏i≤k 1/(1 − xⁱ). Without a generating function, a quick hand-count: fix the number of 5-coins, then count (1,2)-ways as ⌊r/2⌋ + 1.

7. Graph Theory

🟢 Must RememberHandshake lemma

Σ deg(v)=2|E| for undirected graphs. Therefore the number of odd-degree vertices is even.

⚠️ GATE FavouriteConnectivity

For an undirected graph, connected means every pair of vertices has a path. A tree is connected and acyclic.

🧮 Formula / RuleTree invariant

A tree with n vertices has exactly n−1 edges. Adding one edge creates exactly one cycle; deleting any edge disconnects the tree.

🟡 Common TrapEuler vs Hamilton

Euler concerns using every edge; Hamilton concerns visiting every vertex. Do not interchange their conditions.

🧮 Formula / RuleEuler and Hamilton: the exact tests

Euler circuit: connected and every degree even (directed: in-degree = out-degree). Euler path: connected with 0 or 2 odd-degree vertices. Kn has an Euler circuit iff n is odd. Hamilton: no simple iff-test; Dirac (n ≥ 3, every degree ≥ n/2) and Ore (deg u + deg v ≥ n for non-adjacent pairs) are sufficient only. Kn is Hamiltonian for n ≥ 3; Km,n is Hamiltonian iff m = n ≥ 2.

🧮 Formula / RulePlanarity and Euler’s formula

Connected planar graph: V − E + F = 2. For V ≥ 3: E ≤ 3V − 6; if there is no triangle (e.g. bipartite): E ≤ 2V − 4. Sum of face degrees = 2E. K₅ (10 edges > 9) and K₃,₃ (9 edges > 8) are non-planar, and by Kuratowski a graph is planar iff it has no subdivision of either. Example: a connected planar cubic graph on 8 vertices has E = 12 and F = 2 − 8 + 12 = 6.

🧮 Formula / RuleSpanning trees

Cayley: Kn has n^(n−2) spanning trees (K₄ → 16). Km,n has m^(n−1)·n^(m−1) (K₂,₃ → 12; K₃,₃ → 81). The cycle Cn has n. In general use the matrix-tree theorem (any cofactor of the Laplacian). A spanning tree has n−1 edges; if all edge weights are distinct the minimum spanning tree is unique (Kruskal/Prim); cut property and cycle property justify both algorithms.

🟢 Must RememberConnectivity and special graph counts

Vertex connectivity κ ≤ edge connectivity λ ≤ minimum degree δ. In a tree every edge is a bridge and every non-leaf is a cut vertex. A forest with n vertices and c components has n − c edges. Kn has n(n−1)/2 edges; Km,n has mn. There are 2^(n(n−1)/2) labelled simple graphs on n vertices (64 for n = 4) but only 11 non-isomorphic ones. A graph is bipartite iff it has no odd cycle.

🟢 Must RememberDirected graphs

Σ in-degree = Σ out-degree = |E|. The (i,j) entry of Aᵏ counts walks of length k from i to j. A digraph is strongly connected if every vertex reaches every other; a DAG has a topological order (a vertex with in-degree 0 always exists).

🟢 Must RememberMatching, vertex cover, independent set, edge cover

For a graph on n vertices: α + τ = n (independent set + vertex cover) and ν + ρ = n (matching + edge cover, no isolated vertices — Gallai). König (bipartite graphs): ν = τ, hence α = n − ν; Hall's condition characterises perfect matchings. Perfect matchings: Kn,n has n!, K2n has (2n − 1)!! (K₆: 15, K₈: 105); a tree has at most one; every regular bipartite graph has one. The Petersen graph has a perfect matching and independence number 4.

🟢 Must RememberGraph colouring

χ(G) ≥ ω(G) (clique number) but not always equal: the Grötzsch graph is triangle-free with χ = 4, and C₅ has ω = 2, χ = 3. Brooks: χ ≤ Δ unless G is complete or an odd cycle; χ ≤ Δ + 1 always; planar ⇒ χ ≤ 4; bipartite ⇔ χ ≤ 2; the Petersen graph has χ = 3. Chromatic polynomial P(G,k) (colourings with k colours): tree k(k−1)ⁿ⁻¹; Kn k(k−1)…(k−n+1); cycle Cn (k−1)ⁿ + (−1)ⁿ(k−1); deletion–contraction P(G) = P(G − e) − P(G / e); disconnected graphs multiply. Edge colouring: Δ ≤ χ′ ≤ Δ + 1 (Vizing); bipartite χ′ = Δ; χ′(Kn) = n − 1 for even n and n for odd n.

🧮 Formula / RuleDegree sequences, complements and extremal counts

Havel–Hakimi: sort descending, delete the largest d₁ and subtract 1 from the next d₁ entries; repeat. The sequence is graphic iff you reach all zeros without a negative entry. An even sum is necessary, not sufficient. Complement: |E(G)| + |E(Ḡ)| = C(n,2); a self-complementary graph has n ≡ 0 or 1 (mod 4) (P₄, C₅). Mantel: a triangle-free graph has at most ⌊n²/4⌋ edges (attained by K⌊n/2⌋,⌈n/2⌉). Unlabelled trees on n = 1…8 vertices: 1, 1, 1, 2, 3, 6, 11, 23; non-isomorphic simple graphs on n = 1…6: 1, 2, 4, 11, 34, 156; connected 3-regular graphs on 6 vertices: 2 (K3,3 and the prism).

🧮 Formula / RuleRooted trees and m-ary trees

A full m-ary tree with i internal vertices has n = m·i + 1 vertices and (m − 1)·i + 1 leaves (binary: i + 1 leaves, 2i + 1 vertices). A binary tree of height h (edges) has at most 2^(h+1) − 1 vertices and at most 2h leaves; with n₂ vertices of degree 2 it has n₂ + 1 leaves. Binary search trees on n keys: Catalan number Cn. A tree has one or two centre vertices.

🧮 Formula / RuleConnectivity, planarity bounds, Euler and Hamilton extras

A cut vertex increases the number of components when removed; a bridge is an edge with that property; blocks are the maximal 2-connected pieces, and consecutive blocks meet at cut vertices. Planar with girth g: E ≤ g(V − 2)/(g − 2): triangle-free (g = 4) gives E ≤ 2V − 4 (K2,8 reaches 16 for V = 10), and the Petersen graph (g = 5, E = 15 > 5·8/3) is non-planar. Km,n has an Euler circuit iff m and n are both even; it has an Euler trail but no circuit when exactly two vertices have odd degree (K2,3). The Petersen graph has a Hamilton path but no Hamilton cycle.

🧭 Problem → Standard Method Guide

Use this immediately before PYQs: identify the pattern first, then apply the standard technique.

Logic & Proof Patterns

Truth/equivalence question → use truth table or standard logical equivalences. Check only the relevant rows/identities.

Implication validity → rewrite P→Q as ¬P∨Q; look for the single false case.

Quantifier negation → push negation inward while flipping ∀↔∃. Do not negate the predicate incorrectly.

Argument validity → translate premises/conclusion into logic; test whether premises true can coexist with conclusion false.

Relations, Functions, Posets & Lattices

Classify a relation → systematically test reflexive, symmetric, antisymmetric, transitive using counterexamples where possible.

Equivalence classes → verify equivalence relation, then group elements related to a chosen representative.

Partial-order question → check R, AS, T. For Hasse diagrams, remove loops and transitive edges.

Least/greatest/minimal/maximal → compare using the order relation, not visual position alone.

Lattice question → for each relevant pair, find both meet (GLB) and join (LUB).

Function classification → injective: compare inputs/outputs; surjective: check every codomain value has a preimage; bijective: both.

Combinatorics

“At least one” → complement counting: total − none.

Overlapping cases → Inclusion–Exclusion; watch alternating signs.

Repeated objects / identical items → divide by factorials of repetition counts when appropriate.

Restricted arrangements → count unrestricted arrangements and subtract invalid cases, or use block/gap methods depending on the restriction.

Guaranteed repetition → Pigeonhole principle; formulate the boxes and objects explicitly before calculating.

Choose r from n → combinations when order does not matter; permutations when it does.

Recurrences & Generating Functions

Constant-coefficient linear recurrence → characteristic equation → roots → homogeneous solution → particular solution → initial conditions.

Repeated characteristic root → multiply successive terms by powers of n.

Non-homogeneous recurrence → solve homogeneous part first, then construct a particular solution.

Generating-function problem → define the series, transform the recurrence/sequence algebraically, then extract coefficients.

8. High-Yield Extensions & Standard Methods

🟢 Must RememberGraph isomorphism

An isomorphism is a bijection preserving adjacency. Before attempting a mapping, compare invariants: number of vertices/edges, degree multiset, connected components, cycle structure and counts of special vertices.

⚠️ GATE FavouriteCosets

For subgroup H of finite group G, every left coset has |H| elements and cosets partition G. By Lagrange, |H| divides |G| and the number of distinct cosets is |G|/|H|.

🧮 Formula / RuleHomomorphism

A map preserves the operation: f(a*b)=f(a)*f(b). For group homomorphisms, the kernel is a subgroup and the image is a subgroup; injective iff the kernel is the identity-only set.

🟡 Common TrapHomomorphism vs isomorphism

A homomorphism only has to preserve the operation, so it need not be injective or onto; an isomorphism is a bijective homomorphism. The kernel measures failure of injectivity: for finite groups |image| = |G| / |kernel|.

🟢 Must RememberHall's condition

A bipartite graph has a matching saturating the left side iff for every subset S of left vertices, |N(S)| ≥ |S|.

🧮 Formula / RuleColouring bounds

χ(G) ≥ ω(G), where ω is clique number. A nonempty bipartite graph has chromatic number 2. For a complete graph Kn, χ=n.

🟢 Must RememberGenerating-function workflow

Translate the recurrence/counting condition into coefficient extraction. Use geometric-series identities for unrestricted repetition and multiply generating functions when independent choices combine.

💡 ShortcutGraph invariant filter

If two graphs have different degree multisets, component counts, or vertex/edge counts, they are immediately non-isomorphic; do not attempt a full mapping.

Representative worked problems

Q1 · Cosets and subgroup order

Given: |G|=24 and H is a subgroup of order 6. How many distinct left cosets of H exist?

Method: Use the coset partition theorem: number of cosets = |G|/|H|.

24/6 = 4. Every coset contains exactly 6 elements and the four cosets partition G.

Q2 · Graph isomorphism filter

Given: G has degree sequence (3,2,2,1,1,1) while H has (3,3,1,1,1,1). Can they be isomorphic?

Method: Isomorphism preserves the degree of every vertex, hence preserves the sorted degree multiset.

The sequences differ, so the graphs are not isomorphic. No vertex mapping needs to be attempted.

Q3 · Hall's theorem

Given: Left vertices {a,b,c} have neighborhoods N(a)={1,2}, N(b)={2,3}, N(c)={1,2,3}. Does a matching saturating the left side exist?

Method: Check Hall's condition for every relevant subset. Singletons have at least one neighbor; {a,b} has {1,2,3}; {a,c} and {b,c} also have 3; all three have 3.

Thus |N(S)|≥|S| for every S, so Hall's theorem guarantees a matching saturating {a,b,c}. One such matching is a→1, b→2, c→3.

Q4 · Generating function coefficient

Problem: Find the number of solutions to x+y+z=5 with x,y,z≥0.

Method: Each variable contributes 1/(1-t); multiply and extract [t5].

(1-t)-3 = Σ C(n+2,2)tn, so the coefficient of t5 is C(7,2)=21.

Q1 · LOGIC · MCQ — Truth assignments of a cyclic implication

How many assignments to (p, q, r) make (p → q) ∧ (q → r) ∧ (r → p) true?

  1. 1
  2. 2
  3. 4
  4. 6
p → q → r → p forms a cycle of implications.
  If any one variable is T, the chain forces the next one T, and so on around the cycle, so all three are T.
  If none is T, all three are F and every implication F → F is true.
So the formula holds exactly when p = q = r:  TTT and FFF.
Check: p = T, q = F makes p → q false, so mixed assignments always fail.

Correct: Option 2 — 2 assignments.

Q2 · FOL · MCQ — Negating a universal implication

Which formula is logically equivalent to ¬∀x (P(x) → Q(x))?

  1. ∀x (P(x) ∧ ¬Q(x))
  2. ∃x (P(x) → ¬Q(x))
  3. ∃x (¬P(x) ∧ Q(x))
  4. ∃x (P(x) ∧ ¬Q(x))
Step 1: ¬∀x φ(x) ≡ ∃x ¬φ(x), so we get ∃x ¬(P(x) → Q(x)).
Step 2: ¬(P → Q) ≡ ¬(¬P ∨ Q) ≡ P ∧ ¬Q.
Result: ∃x (P(x) ∧ ¬Q(x)) — there is a counter-example element with P true and Q false.
Trap: ∃x (P(x) → ¬Q(x)) is true whenever some x has P false, so it says something much weaker.

Correct: Option 4 — ∃x (P(x) ∧ ¬Q(x)).

Q3 · RELATIONS · MCQ — Reflexive and symmetric relations

How many relations on {1, 2, 3} are both reflexive and symmetric?

  1. 8
  2. 4
  3. 16
  4. 64
Reflexive: all 3 diagonal pairs (1,1), (2,2), (3,3) must be present — no choice.
Symmetric: off-diagonal pairs come in mirrored couples. The unordered pairs are {1,2}, {1,3}, {2,3}, i.e. 3 independent choices.
Each choice is in or out, so the count is 2^3 = 8.
(For comparison: reflexive only = 2^6 = 64, symmetric only = 2^6 = 64.)

Correct: Option 1 — 8 relations.

Q4 · FUNCTIONS · NAT — Counting onto functions

How many onto functions exist from a 5-element set to a 3-element set?

NAT — enter a number.

Inclusion–Exclusion over the codomain elements that are missed:
  onto = 3^5 − C(3,1)·2^5 + C(3,2)·1^5 − C(3,3)·0^5
       = 243 − 3·32 + 3·1 − 0
       = 243 − 96 + 3 = 150.
Cross-check using Stirling numbers: S(5,3) = 25 partitions, each assigned to the 3 codomain values in 3! = 6 ways: 25 × 6 = 150.

Answer: 150

Q5 · POSETS · MCQ — Hasse diagram of a divisor poset

How many edges does the Hasse diagram of the divisors of 36 under divisibility have?

  1. 9
  2. 10
  3. 12
  4. 14
Divisors of 36 = 2^a · 3^b with a, b ∈ {0,1,2}, so the poset is a 3 × 3 grid (9 elements).
Cover relations multiply by exactly one prime:
  multiply by 2: a goes 0→1 or 1→2 (2 steps) for each of 3 values of b → 6 edges
  multiply by 3: b goes 0→1 or 1→2 (2 steps) for each of 3 values of a → 6 edges
Total = 6 + 6 = 12.

Correct: Option 3 — 12 edges.

Q6 · LATTICES · MCQ — Complemented elements in D12

In the lattice of divisors of 12 under divisibility, how many elements have a complement?

  1. 2
  2. 4
  3. 5
  4. 6
Bottom = 1, top = 12. x and y are complements iff gcd(x,y) = 1 and lcm(x,y) = 12.
  1 ↔ 12 (gcd 1, lcm 12)
  3 ↔ 4  (gcd 1, lcm 12)
  2: needs gcd(2,y)=1, so y ∈ {1,3}; lcm(2,1)=2 and lcm(2,3)=6, neither is 12 → no complement
  6: needs gcd(6,y)=1, so y = 1; lcm(6,1)=6 ≠ 12 → no complement
Elements with a complement: 1, 3, 4, 12 → 4.
This also shows D12 is not a Boolean algebra (12 is not square-free).

Correct: Option 2 — 4 elements.

Q7 · GROUPS · MCQ — Subgroups of a cyclic group

How many subgroups does the cyclic group Z36 have?

  1. 6
  2. 8
  3. 12
  4. 9
A cyclic group of order n has exactly one subgroup for each divisor of n.
Divisors of 36: 1, 2, 3, 4, 6, 9, 12, 18, 36 → 9 divisors.
So Z36 has 9 subgroups (orders 1, 2, 3, 4, 6, 9, 12, 18, 36).

Correct: Option 4 — 9 subgroups.

Q8 · GROUPS · MCQ — Units modulo 8

Let S = {1, 3, 5, 7} under multiplication modulo 8. Which statement is true?

  1. It is not a group because 3 · 5 = 15 is outside S
  2. It is a cyclic group generated by 3
  3. It is a group in which every element is its own inverse, so it is not cyclic
  4. It is a group isomorphic to Z4
Closure: 3·5 = 15 ≡ 7, 3·7 = 21 ≡ 5, 5·7 = 35 ≡ 3 — all in S. Identity is 1; multiplication mod 8 is associative.
Squares: 3² = 9 ≡ 1, 5² = 25 ≡ 1, 7² = 49 ≡ 1, so every element is its own inverse.
A cyclic group of order 4 needs an element of order 4. Here every non-identity element has order 2.
So S is the Klein four-group, not Z4.

Correct: Option 3 — Group, all elements self-inverse, not cyclic.

Q10 · COMBINATORICS · NAT — Inclusion–Exclusion with three divisors

How many integers from 1 to 1000 are divisible by none of 3, 5 and 7?

NAT — enter a number.

Let A, B, C be the multiples of 3, 5, 7 up to 1000.
|A| = 333, |B| = 200, |C| = 142
|A∩B| = ⌊1000/15⌋ = 66, |A∩C| = ⌊1000/21⌋ = 47, |B∩C| = ⌊1000/35⌋ = 28
|A∩B∩C| = ⌊1000/105⌋ = 9
|A∪B∪C| = (333 + 200 + 142) − (66 + 47 + 28) + 9 = 675 − 141 + 9 = 543
None of the three: 1000 − 543 = 457.

Q11 · COMBINATORICS · MCQ — Bounded solutions of an equation

How many integer solutions does x + y + z = 12 have with 0 ≤ x, y, z ≤ 6?

  1. 28
  2. 36
  3. 45
  4. 91
Without the upper bound: C(12 + 2, 2) = C(14, 2) = 91.
Bad solutions have some variable ≥ 7. Substitute x' = x − 7: x' + y + z = 5, giving C(7, 2) = 21 solutions. There are 3 choices of variable → 63.
Two variables ≥ 7 would need a sum ≥ 14 > 12, impossible, so there is no overlap to add back.
Valid = 91 − 63 = 28.

Correct: Option 1 — 28 solutions.

Q12 · RECURRENCE · MCQ — Recurrence with a repeated root

a_n = 6a_(n−1) − 9a_(n−2) with a_0 = 1 and a_1 = 9. What is a_4?

  1. 486
  2. 567
  3. 729
  4. 972

a_0 = 1 → C0 = 1.  a_1 = 3(1 + C1) = 9 → C1 = 2.
So a_n = (1 + 2n)·3^n and a_4 = 9 · 81 = 729.

Q14 · TREES · MCQ — Counting vertices of a tree from degrees

  2. 11
  3. 13
  4. 12

Q16 · FOL · MCQ — Which quantified implication is valid?

Which of the following first-order formulas is valid (true in every interpretation)?

  1. ∀x (P(x) ∨ Q(x)) → (∀x P(x) ∨ ∀x Q(x))
  2. (∃x P(x) ∧ ∃x Q(x)) → ∃x (P(x) ∧ Q(x))
  3. ∃x (P(x) ∧ Q(x)) → (∃x P(x) ∧ ∃x Q(x))
  4. (∀x P(x) → ∀x Q(x)) → ∀x (P(x) → Q(x))
